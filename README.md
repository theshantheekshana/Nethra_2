# NETHRA (private operator tool)
1. `npm i`  2. Deploy/run with Vercel (`npx vercel dev`) so `/api/generate` runs.
Env vars: ANTHROPIC_API_KEY, NETHRA_ACCESS_KEY (you enter it once in the app), optional AI_MODEL, AI_PROVIDER (default anthropic).
PDF: "Download PDF" opens the print dialog -> Save as PDF (Chrome/Edge, keep "Background graphics" on).
